title: TCP/IP Protocol Suite and Architecture
overview: The Internet protocol suite (TCP/IP) defines the networking protocols and communication architecture powering the global Internet.

## Layered Architecture
The TCP/IP model comprises four layers: Link Layer (Ethernet, Wi-Fi), Internet Layer (IP, ICMP, ARP), Transport Layer (TCP, UDP), and Application Layer (HTTP, DNS, TLS, SSH).

## TCP Reliable Transport
Transmission Control Protocol (TCP) establishes connections via a three-way handshake (SYN, SYN-ACK, ACK), providing ordered byte-stream delivery, sliding window flow control, and congestion control algorithms (Reno, Cubic, BBR).
