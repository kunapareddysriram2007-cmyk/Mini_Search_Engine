## Memory Hierarchy
Computer memory architecture includes register memory, L1 memory cache, L2 memory cache, L3 memory cache, main RAM memory, and secondary memory swap storage. The memory controller coordinates memory read and memory write operations across memory buses to maintain memory coherence.
